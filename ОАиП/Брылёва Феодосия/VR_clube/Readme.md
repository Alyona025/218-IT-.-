## Вопросы к занятию

**1. Почему проверку возраста удобно сделать через if, а выбор номера тарифа — через switch?**
Через `if` легко задавать диапазоны чисел с помощью операторов сравнения (`<`, `>`, `<=`) и логических связок (`||`, `&&`). Конструкция `switch` не работает с интервалами, зато идеально подходит для выбора из фиксированного списка точных значений (пунктов меню).

**2. Что произойдёт в вашем switch, если убрать break из case 1?**
Выполнение программы не остановится внутри `case 1` и «провалится» дальше в `case 2`. В итоге переменная `price` сначала получит значение `500`, а сразу следом перезапишется на `700`.
